    10. Ejemplo 08 - Las etiquetas relacionadas con las listas

    El siguiente ejemplo se centra en las etiquetas que muestran listas. Ya las hemos visto en el ejemplo anterior: la lista desplegable, las casillas de selección y los botones de opción. El formulario de prueba será el siguiente:

    10.1. El proyecto de NetBeans

    El proyecto de NetBeans es el siguiente:

    • en [1] la acción y en [2] la vista asociada.

    El archivo [example/example.xml] configura la aplicación:

    
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE struts PUBLIC
        "-//Apache Software Foundation//DTD Struts Configuration 2.0//EN"
        "http://struts.apache.org/dtds/struts-2.0.dtd">

<struts>
  <package name="example" namespace="/example" extends="struts-default">
    <action name="Form" class="example.Form">
      <result name="success">/example/Form.JSP</result>
    </action>
  </package>
</struts>

    Las líneas 8 y 9 muestran que una llamada a URL [/example/Form.action] genera la vista [/example/Form.JSP]. Por lo tanto, la acción [Form] se encargará de construir la plantilla de la vista [Form.JSP].

    Analicemos las diferentes etiquetas de entrada del formulario:

    • línea 27: la etiqueta <s:select>: 
    
      <s:select name="select1" list="{'vert','jaune','rouge'}" size="1" key="Form.select1"/>

    Esta etiqueta generará el siguiente código HTML:

    1

    <select name="select1" size="1" id="Form_select1">
    <option value="vert">vert</option>
    <option value="jaune" selected="selected">jaune</option>
    <option value="rouge">rouge</option>
</select>

    El valor del atributo list es una tabla de cadenas de caracteres que se utiliza para generar los valores y los nombres de las opciones. La plantilla asociada es el campo select1 de la acción [Form] siguiente:

    
  private String select1 = "jaune";

    Este campo está asociado, tanto en lectura como en escritura, a la etiqueta denominada select1. En escritura, el valor de la opción seleccionada se insertará en el campo select1. En lectura, el valor del campo select1 sirve para determinar la opción seleccionada. Aquí, el valor jaune del campo select1 sirve para seleccionar la opción de la etiqueta select1 que tiene el valor amarillo. Por eso, en la línea 3, la opción está seleccionada.

    • línea 28 
    
<s:select name="select2" list="{'vert','jaune','rouge'}" size="3" key="Form.select2" multiple="true"/>

    No hay ninguna diferencia fundamental con la etiqueta de la línea 27, salvo que aquí la selección es múltiple. Por lo tanto, el valor enviado es una matriz de valores, los de las opciones seleccionadas. El campo select2 de la acción asociada al formulario es el siguiente:

    
  private String[] select2 = new String[]{"vert", "rouge"};

    Efectivamente, es una matriz. Su valor inicial sirve para seleccionar las opciones cuyos valores están presentes en la matriz.

    • línea 29 
    
      <s:select name="select3" list="#{'01':'vert(01)','02':'jaune(02)','03':'rouge(03)','04':'blanc(04)','05':'noir(05)'}" size="3" key="Form.select3" multiple="true"/>

    Aquí, el valor del atributo list es un diccionario cuyas claves sirven como valores para las opciones y los valores asociados sirven como etiquetas para las opciones. El código HTML generado es el siguiente:

    <option value="04">blanc(04)</option>
    <option value="05">noir(05)</option>

    El campo asociado en la acción es el siguiente:

    
  private String[] select3 = new String[]{"01", "03"};

    De nuevo tenemos una tabla de valores porque la etiqueta asociada es de opción múltiple. Los valores iniciales de la tabla explican por qué las opciones de las líneas 2 y 4 están seleccionadas inicialmente.

    • línea 30 
    
      <s:select name="select4" list="dico" size="3" key="Form.select4" multiple="true"/>

    Aquí, las opciones de la lista serán proporcionadas por el modelo de la vista, modelo que en este caso forma parte de la acción [Form]:

    
private HashMap<String, String> dico = new HashMap<String, String>();

    Las claves del diccionario dico serán los valores de las opciones. Los valores del diccionario dico serán los nombres de las opciones. El campo select4 de la acción es el siguiente:

    
  private String[] select4 = new String[]{"1", "3"};

    Se trata de una tabla de valores que recibirá los valores enviados por la etiqueta select4.

    • línea 31 
    
<s:select name="select5" list="couleurs" listKey="id" listValue="nom" size="3" key="Form.select5" multiple="true" />

    La lista de opciones es generada por el campo couleurs, definido por el atributo list. El campo couleurs de la acción [Form] se define de la siguiente manera:

    
private Couleur[] couleurs;

    La clase [Couleur] se define de la siguiente manera:

    
package example;

public class Couleur {

  // campos
  private String id;
  private String nom;

  // constructor
  public Couleur(){
  }

  // getter y setter
...  
}

    Tiene dos campos llamados id y nom. En la etiqueta select5 tenemos listKey="id" listValue="nom".. Esto significa que el campo id servirá como valor para una opción y el campo nom servirá como texto descriptivo. Cabe recordar que son los valores de las opciones los que se registran. Estos se registrarán en el siguiente campo select5:

    
  private String[] select5 = new String[]{"1", "3"};

<s:checkboxlist name="checkboxlist1" list="#{'01':'vert(01)','02':'jaune(02)','03':'rouge(03)','04':'blanc(04)','05':'noir(05)'}" key="Form.checkboxlist1"/>

  public String getSelect2SelectedValues() {
    return getArrayValue(select2);
  }

  // métodos de utilidad
  public String getArrayValue(String[] values) {

    for (String value : values) {

    El método getSelect2SelectedValues convierte los valores de la tabla select2 en una cadena de caracteres.

    10.4. La acción [Form]

    Al comentar la vista [Form.JSP], presentamos los campos de la acción [Form] asociada. El código de la acción [Form] es el siguiente:

    
package example;

import com.opensymphony.xwork2.ActionSupport;
import java.util.HashMap;

public class Form extends ActionSupport {

  // campos del formulario
  private String select1 = "jaune";
  private String[] select2 = new String[]{"vert", "rouge"};
  private String[] select3 = new String[]{"01", "03"};
  private String[] select4 = new String[]{"1", "3"};
  private String[] select5 = new String[]{"1", "3"};
  private HashMap<String, String> dico = new HashMap<String, String>();
  private Couleur[] couleurs;
  private String[] checkboxlist1 = new String[]{"01", "03"};
  private String[] checkboxlist2 = new String[]{"1", "3"};
  private String[] checkboxlist3 = new String[]{"1", "3"};
  private String radio1="01";
  private String radio2="1";
  private String radio3="1";

  private String submitText;

  // constructor sin parámetros
  public Form() {
    // inicialización del diccionario de colores
    dico.put("1", "vert(1)");
    dico.put("2", "jaune(2)");
    dico.put("3", "bleu(3)");
    dico.put("4", "rouge(4)");
    dico.put("5", "blanc(5)");

    // inicialización de la matriz de objetos Color
    couleurs = new Couleur[dico.size()];
    int i = 0;
    for (String key : dico.keySet()) {
      couleurs[i] = new Couleur();
      couleurs[i].setId(key);
      couleurs[i].setNom(dico.get(key));
      i++;
    }
  }

  // valores seleccionados en listas desplegables
  public String getSelect2SelectedValues() {
    return getArrayValue(select2);
  }

  public String getSelect3SelectedValues() {
    return getArrayValue(select3);
  }

  public String getSelect4SelectedValues() {
    return getArrayValue(select4);
  }

  public String getSelect5SelectedValues() {
    return getArrayValue(select5);
  }

  public String getCheckboxlist1SelectedValues() {
    return getArrayValue(checkboxlist1);
  }

  public String getCheckboxlist2SelectedValues() {
    return getArrayValue(checkboxlist2);
  }
  public String getCheckboxlist3SelectedValues() {
    return getArrayValue(checkboxlist3);
  }

  // métodos de utilidad
  public String getArrayValue(String[] values) {
    String result = "";
    for (String value : values) {
      result += " " + value;
    }
    return result;
  }

  // getters y setters
   ...
}

    No se encuentra ningún método execute en esta acción. Por lo tanto, se ejecuta el método execute de la clase padre ActionSupport. Este no hace nada y simplemente devuelve la clave de navegación SUCCESS.
